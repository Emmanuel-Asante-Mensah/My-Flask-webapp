# 🌐 Flask Profile & Payment Web App

## 🚀 Overview
This is a Flask-based web application designed for both customers and vendors.  
It provides secure profile management, session handling, and integrated payment options (MoMo & Visa).  
The app is built with clean, consistent styling and responsive layouts for a smooth user experience.

## ✨ Features
- Customer and vendor profile creation & management
- Secure authentication and session handling
- Integrated payment gateway (MoMo, Visa)
- Responsive UI with consistent styling
- Easy-to-extend modular Flask structure
